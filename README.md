Es un sistema de gestion de citas para un estudio de tatuajes "Tattoora"

Su proposito es optimizar los procesos operativos del estudio, permitiendo que al agendar una cita haya mas control
y sea más eficiente, tener un historial de los clientes,reportes de ventas, clientes y trabajadores, 
un mejor seguimiento de anticipos, pagos finales y tambien un seguimiento post-servicio con cada cliente para dar 
recomendaciones despues de su cita.

¿Como se instala?
Para instalarlo debemos contar con Node.js, Git, npm
Clonamos e instalamos localmente
https://github.com/RubiBarragan12/Equipo-despliegue-.git
Accedemos a la carpeta del proyecto: cd Equipo-despliegue-, e instalamos: npm intall

¿Como se ejecuta?
despues de la instalación ejecutamos con el comando npm run dev, abrimos el navegadoe
e ingresamos a http://localhost:4000
