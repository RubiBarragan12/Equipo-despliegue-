Es un sistema de gestion de citas para un estudio de tatuajes "Tattoora"

Su proposito es optimizar los procesos operativos del estudio, permitiendo que al agendar una cita haya mas control
y sea más eficiente, tener un historial de los clientes,reportes de ventas, clientes y trabajadores, tener 
un mejor seguimiento de anticipos, pagos finales, tambien tenemos un seguimiento post-servicio con cada cliente para dar 
recomendaciones despues de su cita.
